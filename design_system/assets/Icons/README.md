# Icons

The Aqui icon set as single-ink SVG files: 16×16 grid, 1.5 px stroke, square caps, mitred joins. Files are drawn in `#0f1f2f` (ink-1, light theme); in the app use the `Icon` component (which inherits `currentColor`) or inline the SVG and set `stroke`/`fill` to the token you need. Filled shapes appear only in polarity (`support` ▲, `contra` ▼, `neutral` ●) and a few solid glyphs (`running`, `play`, `pause`, `back`, `forward`).

- Actors: `model` (eye — observes), `solver` (balance — decides), `team` (person — answers).
- Registers: `infer` (∴ inference line), `estimate` (≈ estimate line).
- Evidence kinds: `text`, `object`, `checklist`, `measure`, `sun`, `compass`, `language`, `neighbour`, `region`, `name`, `contradiction`.
- Stage status: `queued`, `running`, `done`, `skipped`, `failed`, `timeout`.
- Human loop and cost: `cost` (tag), `question`, `cue`, `skip`, `clock`, `key`.
- Panorama and map: `layers`, `hidden`, `crosshair`, `camera`, `photo`, `mask`, `sector`, `skyline`, `water`, `zoom`, `ruler`, `pin`, `matrix`, `bracket`.
- Actions and system: `link`, `copy`, `qr`, `download`, `drop`, `submit`, `file`, `play`, `pause`, `back`, `forward`, `replay`, `chevronDown`, `chevronRight`, `close`, `plus`, `minus`, `warning`, `info`, `lock`, `gpu`, `online`, `offline`, `clean`, `special`.

Always pair an icon that carries meaning with a word. No emoji.
