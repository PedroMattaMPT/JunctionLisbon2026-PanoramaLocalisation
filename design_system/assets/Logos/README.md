# Logos

- `aqui-wordmark.svg` — for light grounds (limestone, paper). Letters in `#0f1f2f` (ink-1, light), tittle in `#5d4201` (solver, light).
- `aqui-wordmark-on-dark.svg` — for Atlantic-ink grounds. Letters in `#ecf1f5` (ink-1, dark), tittle in `#f4d16d` (solver, dark).
- `aqui-mark.svg` — favicon and app icon, 64×64 on `#0d1d2a` (surface-1, dark): the i with its tittle as a point inside a broken uncertainty ring. Reads down to 16 px.

The letters are Newsreader outlines (opsz 72, weight 520); the tittle is drawn, not a glyph. Keep one x-height of clear space; never recolour the tittle to anything but the solver colour. "Aqui" is a working name: replace these three files (and the `Wordmark` component) to rename.
