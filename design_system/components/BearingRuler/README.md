# BearingRuler

The 0–360° ruler under the panorama: camera yaw until the sun fixes north, then true bearings with the fix's ± error band.

- **Provide:** `width`, `mode`, `offset` (bearing of yaw 0), `err`, optional `marks` (selected evidence), `fov`.
- The caption always says which it is: "Camera yaw · north unknown" or "True bearing · sun fix ± 12°".
