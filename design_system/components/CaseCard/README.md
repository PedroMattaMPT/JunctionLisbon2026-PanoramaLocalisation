# CaseCard

A sealed case in the queue: only status crosses between cases — no image, no date, no content.

- **Provide:** `label`, `status` (`waiting`, `processing`, `needs-answer`, `done`, `submitted`), optional `special`, `multiplier`, `expected`, `used`, `stage`, `elapsed`, `current`, `gain`.
- Never group or sort cards by date; never hint that two were taken the same day.
