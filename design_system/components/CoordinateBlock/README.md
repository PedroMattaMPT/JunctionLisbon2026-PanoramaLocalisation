# CoordinateBlock

The coordinate, once, in mono with a true minus — with its order, uncertainty, source role, method, radius source and the multiplier when produced.

- **Provide:** `a` (`lat`, `lng`, `r`, `rSource`, `role`, `method`, `multiplier`), optional `showCopy`, `size`.
- Extra decimals never imply precision: the ± radius is always beside it.
