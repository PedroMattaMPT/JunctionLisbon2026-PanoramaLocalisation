# Density

Sets console or stage density, and optionally a theme, for a subtree.

- **Provide:** `value` (`console` | `stage`), optional `theme` (`dark`, `light`, `stage`), `children`.
- Stage switches type to the `stage-*` styles (body 24 px), doubles spacing and line weights. Use `theme="stage"` for the projector window and `theme="light"` for the printable report.
