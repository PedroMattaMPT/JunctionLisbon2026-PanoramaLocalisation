# FilenameParse

The filename is the only side information: date, UTC time and shot counter, shown split, with the Urban label, its source and the Special One flag.

- **Provide:** `file`, `urban`, `source` (`official` | `inferred` | `unknown`), `special`, `size`, optional `status`, `message`, `editable`.
- An unparsed name says what is lost ("the sun cannot fix north").
