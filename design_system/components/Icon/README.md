# Icon

The Aqui icon set: 16 px grid, 1.5 px stroke, square caps, `currentColor`; filled shapes only for polarity (▲ ▼ ●).

- **Provide:** `name` (see the preview; also `ICONS`), optional `size`, `title` (makes it non-decorative).
- Actor icons: `model` (eye), `solver` (balance), `team` (person). Register icons: `infer` (∴), `estimate` (≈).
- Always beside a word when the icon carries meaning. No emoji anywhere.
