# QuestionOption

One option: lettered key in its option colour, label, one-line reason, evidence chips, representative point ("not a camera position") and links to OSM, Google Maps and Street View.

- **Provide:** `o` (`key`, `label`, `reason`, `chips`, `point`, `none`), optional `state` (`open`, `chosen`, `other`, `skipped`), `evidence`, `cost`, `hover`, `showLinks`, `brief`.
- "None of these" exists only when the agent made it an option.
