# Stamp

A verdict stamp — RULED OUT, CONFIRMED BY MATCH, SUBMITTED, ESTIMATE — the only capitals in the system, at most one in view.

- **Provide:** `kind` (`ruled-out`, `confirmed`, `submitted`, `estimate`) or custom `children`.
- Rotated −3°, 2 px border in the verdict colour. Use on the report, the ruled-out row in focus, and the final answer heading.
