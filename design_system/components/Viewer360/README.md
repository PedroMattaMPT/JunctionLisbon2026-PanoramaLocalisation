# Viewer360

The interactive 360° viewer frame (Pannellum in the app), kept in sync with the strip on yaw.

- **Provide:** `c`, `yaw`, optional `pitch`, `fov`, `width`, `height`, `selected`, `synced`.
- Caption: yaw, bearing ± error once known, field of view, and "synced with strip" (or "not synced — click to re-sync").
