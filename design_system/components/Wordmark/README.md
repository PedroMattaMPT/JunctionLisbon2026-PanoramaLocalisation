# Wordmark

The "aqui" wordmark: Newsreader outlines with the tittle drawn as a point inside a broken uncertainty ring ("here, ± how sure"); `mark` draws only the i for favicons.

- **Provide:** `size` (height in px), optional `mark`, `title`.
- Letters take `ink-1`; the tittle takes `solver`. Keep clear space of one x-height. A working name: swap the SVG to rename.
